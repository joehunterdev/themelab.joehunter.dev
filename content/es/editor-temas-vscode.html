El Editor de Temas de VS Code Online que Realmente Muestra VS Code

La mayoría de herramientas de temas para VS Code te sueltan ante una pared de tokens JSON y esperan que te imagines cómo van a quedar. ThemeLab hace lo contrario — renderiza una simulación pixel-perfect del interfaz de VS Code directamente en tu navegador.

Cambia un color y verás la actualización en todo el shell del editor al instante. Cuando estés satisfecho, exporta un archivo de tema .json válido para VS Code con un solo clic.

Qué lo hace diferente

🖥 Simulación real de VS Code

Barra de actividad, sidebar, pestañas, editor, barra de estado — todo reactivo a tus tokens de tema.

⚡ Preview instantáneo

Cada cambio se aplica de inmediato mediante variables CSS. Sin builds, sin recargar.

📦 Exporta JSON válido

Descarga un theme.json que funciona como tema de extensión oficial de VS Code.

🧠 UI consciente de tokens

Cada control mapea a un token real de VS Code para que siempre sepas qué estás editando.

¿Quién lo construyó?

ThemeLab es un proyecto de Joe Hunter, desarrollador full-stack afincado en España. Nació como un reto técnico — construir algo que se vea y se sienta como VS Code, íntegramente en React, sin backend ni código nativo.

El resultado es una herramienta que Joe usa para diseñar sus propios temas, y una demostración de lo que es posible con ingeniería frontend moderna.

Sin instalación. Sin registro. Sin trampa.

ThemeLab funciona completamente en el navegador. Ábrelo, empieza a diseñar, exporta cuando estés listo. Así de simple.
