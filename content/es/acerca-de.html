Acerca de ThemeLab

ThemeLab es un editor de temas para VS Code que funciona directamente en el navegador — construido íntegramente en React y TypeScript como proyecto técnico de Joe Hunter, desarrollador full-stack afincado en España.

La idea es sencilla: la mayoría de las herramientas de temas para VS Code son editores abstractos de JSON. ThemeLab, en cambio, renderiza una simulación visual del interfaz de VS Code y te permite editar los tokens de color en tiempo real, viendo cada cambio al instante antes de exportar un archivo .json válido.

Por qué se construyó

Los desarrolladores pasan horas cada día en su editor, pero pocos personalizan su tema más allá de elegir uno del marketplace. ThemeLab elimina esa fricción — sin extensiones, sin terminal, sin buscar tokens en JSON. Abre el navegador y diseña.

Para Joe, es también un ejercicio técnico deliberado: renderizar una interfaz de editor convincente en React puro, gestionar theming vivo mediante variables CSS a escala, y publicar algo que se siente premium sin dependencias de frameworks de UI.
