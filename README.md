# ThemeLab

> A modern VS Code theme customizer and live editor built with React, Monaco Editor, and TypeScript.

ThemeLab lets developers and designers create, preview, customize, and export beautiful Visual Studio Code themes in real time through an interactive VS Code-inspired interface.

Built for:

* VS Code theme creators
* UI/UX designers
* frontend developers
* design engineers
* open source theme enthusiasts

---

# Features

## Real-Time VS Code Theme Preview

Customize your theme and instantly preview changes across:

* editor background
* syntax highlighting
* sidebar
* activity bar
* tabs
* status bar
* terminal colors

---

## Monaco Editor Integration

ThemeLab uses Monaco Editor — the same editor that powers VS Code — for realistic syntax highlighting and accurate theme rendering.

---

## Interactive Theme Controls

Edit core styling tokens with live controls:

* color pickers
* token groups
* UI sections
* syntax categories

---

## Export VS Code Themes

Generate valid VS Code theme JSON files ready for:

* personal use
* publishing
* extension packaging
* marketplace distribution

---

## Built-In Theme Presets

Includes starter presets inspired by popular themes:

* Dracula
* Nord
* Tokyo Night
* One Dark
* Catppuccin

# Why ThemeLab?

Creating VS Code themes manually is tedious.

Most workflows involve:

* editing JSON files
* restarting editors
* guessing token mappings
* trial-and-error styling

ThemeLab makes the process visual, interactive, and fast.

Instead of editing raw JSON, you can:

1. tweak colors visually
2. preview instantly
3. export production-ready themes

# Getting Started

## Clone the repository

```bash
git clone https://github.com/yourusername/themelab.git
```

## Install dependencies

```bash
cd themelab
npm install
```

## Start development server

```bash
npm run dev
```

# Design Philosophy

ThemeLab is not trying to recreate the entire VS Code application.

Instead, it focuses on:

* visual fidelity
* theme experimentation
* rapid iteration
* clean UX
* realistic previews

The goal is to feel like:

> “Figma for VS Code themes.”
